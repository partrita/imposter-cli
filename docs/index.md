# imposter 사용자 가이드

`imposter`는 실제 코드를 수정하거나 외부 AI 모델을 호출하지 않으면서도, 터미널 화면에 마치 최신 AI 코딩 에이전트와 페어 프로그래밍을 진행하는 듯한 생생한 작업 환경을 연출해 주는 Rust 기반 CLI 도구입니다.

동료나 상사가 지나갈 때 화면만 보면 "지금 대규모 리팩터링과 분산 트랜잭션 최적화 작업을 깊이 있게 진행하고 있구나"라는 인상을 줍니다. 실제로는 파일이 전혀 변경되지 않고, API 토큰이나 네트워크 비용도 0원입니다.

> [!WARNING]
> **Satire / 풍자 목적 안내**
> 본 프로젝트는 개발 문화의 단면을 유쾌하게 풍자하기 위해 만든 유머 도구입니다. 실제 업무 진척 증빙이나 성과 평가 용도로 악용해서는 안 됩니다.

---

## 핵심 차별점

### 1. 주요 AI 코딩 에이전트 CLI 정밀 모사
Claude Code, OpenAI Codex, OpenCode, Pi Agent, Google Antigravity 등 현존하는 주요 AI 코딩 에이전트들의 고유한 프롬프트 스타일, 박스 드로잉, 툴 실행 트리 및 상태바 레이아웃을 실제 환경과 분간하기 어려울 정도로 사실감 있게 구현했습니다.

### 2. 다크 모드 & 라이트 모드 동시 지원
모든 스타일은 기본 다크 모드(`--dark`) 외에도 밝은 배경 터미널 사용자를 위한 고대비 라이트 모드(`--light`) 팔레트를 완벽히 지원합니다. `-i` 대화형 TUI에서도 `t` 키 하나로 즉시 테마를 전환해 볼 수 있습니다.

### 3. 제로 의존성 기반의 극단적인 경량 설계
- **코어 런타임 의존성 0개**: 일반 실행 시 `clap`, `serde`, `tokio`, `rand`, `regex` 등 외부 라이브러리를 일절 사용하지 않습니다. 순수 Rust 표준 라이브러리(`std`)만으로 동작합니다.
- **초소형 바이너리 & 최소 메모리**: TUI를 제외한 코어 빌드는 약 377 KB(TUI 포함 시 약 558 KB)에 불과하며, 실행 중 메모리 점유율(RSS)은 약 2 MB 내외로 극히 가볍습니다.
- **효율적인 스트리밍 I/O**: 화면 전체를 강제로 덮어쓰는 대체 화면 버퍼(Alternate Screen)를 쓰지 않고, 8 KB 내부 버퍼와 단일 줄 버퍼를 재사용하여 라인 단위로 단 한 번의 시스템 호출(`write_all`)을 통해 부드럽게 출력합니다.

### 4. 반복 없는 자연스러운 대사 전개 (`Deck` 시스템)
단순한 무작위 출력이 아닌, 내부 `xorshift64*` 의사 난수 생성기와 Fisher-Yates 알고리즘으로 셔플된 덱(`Deck`) 메커니즘을 사용합니다. 프롬프트, 탐색 대상 파일, 코드 패치 디프, 터미널 명령어 결과가 한 주기 동안 중복 없이 매끄럽게 교체됩니다.

### 5. 풍부한 대화형 TUI 마법사 (`-i`)
인자 없이 처음 실행하거나 `-i` 옵션으로 진입하면 `ratatui` 기반의 대화형 설정 창이 열립니다. 스타일, 테마, 개발 스택, 작업 지속 시간, 기술 용어 수준, 복잡도 등을 키보드로 편리하게 조정하고 우측 실시간 라이브 프리뷰로 즉각 확인할 수 있습니다.
