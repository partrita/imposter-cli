# 대화형 TUI 설정 마법사

`imposter`를 옵션 없이 실행하거나 `imposter -i`를 입력하면, 터미널 전체 화면을 활용하는 직관적인 대화형 탭 기반 마법사(`ratatui` + `crossterm`)가 열립니다.

---

## 1. 탭 구성 안내

대화형 마법사는 3개의 탭 메뉴로 구성되어 있습니다 (`Tab` 또는 숫자 키 `1`, `2`, `3`으로 전환):

### [1] MAIN
- **네온 글로우 애니메이션 배너**: 실행 중 부드럽게 네온 펄스/색상 사이클링 파동이 흐르는 아스키 아트 로고가 표시됩니다.
- **START 버튼**: `Enter` 또는 `Space` 키를 눌러 바로 세션을 실행할 수 있는 대형 스타트 버튼이 제공됩니다.

### [2] SETTINGS
- **좌측 설정 양식 (Configuration Form)**:
  - 스타일(Persona), 모델명(Model), 재생 속도(Speed), 테마(Theme), 세션 지속 시간(Duration)을 방향키로 편리하게 변경하고, 설정을 기본값으로 저장할 수 있습니다.
- **우측 실시간 라이브 프리뷰 (Live Preview)**:
  - 변경한 설정(스타일, 다크/라이트 테마 등)이 우측 창에 실제 CLI와 100% 동일한 서식으로 즉시 반영되어 렌더링됩니다.

### [3] ABOUT
- 캐치프레이즈(*"아무것도 하지 않으면서, 최신 AI 코딩 에이전트로 바이브 코딩하는 척하기"*), 제작자(`deepthought`), GitHub 소스코드 및 원작 크레딧 안내와 핵심 명령어/단축키 요약이 제공됩니다.

---

## 2. 키보드 단축키 안내표

| 탭 / 상황 | 단축키 | 기능 설명 |
|---|---|---|
| **공통** | `Tab` / `BackTab` | 다음 / 이전 탭 메뉴로 순환 이동 |
| **공통** | `1`, `2`, `3` | 원하는 탭 메뉴 번호로 즉시 전환 (`1:MAIN`, `2:SETTINGS`, `3:ABOUT`) |
| **공통** | `q` 또는 `Esc` | 마법사 즉시 종료 |
| **MAIN** | `Enter` / `Space` | 현재 설정값으로 가짜 세션 시작 |
| **SETTINGS** | `↑` / `↓` 또는 `k` / `j` | 설정 항목 간 이동 |
| **SETTINGS** | `←` / `→` 또는 `h` / `l` | 선택된 항목 값 순환 (Duration은 ±5분) |
| **SETTINGS** | `Enter` | Duration/Model 항목 텍스트 편집 진입 또는 Save 실행 |
| **SETTINGS** | `t` | 다크 테마(`dark`)와 라이트 테마(`light`) 즉시 토글 |
| **SETTINGS** | `Ctrl + S` | 현재 옵션값을 기본값으로 영구 저장 (`~/.config/imposter/config.toml`) |

---

## 3. 비-TTY 환경에서의 동작 (Fallback)

SSH 파이프나 CI 환경처럼 터미널의 Raw Mode와 대화형 입력을 지원하지 않는 환경에서 `-i`를 호출할 경우, `ratatui` 전체 화면 대신 표준 입출력(`stdin`/`stdout`)을 통한 순차적 텍스트 질문-답변 모드로 자동 전환되어 안전하게 설정을 진행할 수 있습니다.
