# 대화형 TUI 설정 마법사

`imposter -i`를 입력하거나 설정 파일이 존재하지 않는 최초 실행 시, 터미널 전체 화면을 활용하는 직관적인 대화형 설정 창(`ratatui` + `crossterm`)이 열립니다.

---

## 1. 화면 구성 안내

대화형 마법사는 크게 세 구역으로 이루어져 있습니다:

1. **상단 스타일 바 (Top Style Bar)**
   - 숫자 단축키 `1`부터 `6`까지 각 스타일에 매핑되어 있어, 원하는 스타일 번호나 `t` 키를 눌러 스타일과 테마를 즉시 전환할 수 있습니다.
2. **좌측 설정 양식 (Configuration Form)**
   - 스타일, 테마, 개발 스택, 세션 지속 시간, 전문 용어 수준, 복잡도, 린트 알림 여부를 위아래 화살표로 탐색하고 좌우 방향키로 손쉽게 값을 바꿀 수 있습니다.
   - 각 필드를 선택하면 하단에 해당 설정의 역할과 권장 사용법이 친절하게 설명됩니다.
3. **우측 실시간 라이브 프리뷰 (Live Preview)**
   - 좌측에서 변경한 옵션(스타일, 다크/라이트 테마, 대상 개발 스택의 실제 파일 경로, 복잡도에 따른 체크리스트, 린트 에러 여부)이 **우측 프리뷰 창에 100% 동일한 서식으로 즉시 반영**되어 렌더링됩니다.

---

## 2. 키보드 단축키 안내표

| 단축키 | 기능 설명 |
|---|---|
| `↑` / `↓` 또는 `k` / `j` | 설정 항목 간 상하 이동 |
| `←` / `→` 또는 `h` / `l` | 선택된 항목의 값 변경 (옵션 순환, 시간은 ±5분씩 조절) |
| `1` ~ `6` | 6가지 스타일 즉시 전환 (`1:claude`, `2:codex`, `3:opencode`, `4:pi`, `5:antigravity`, `6:classic`) |
| `t` | 다크 테마(`◰ dark`)와 라이트 테마(`☼ light`) 즉시 토글 |
| `Enter` 또는 `Space` | 옵션값 다음 순환. 단, `Duration` 필드에서 누르면 원하는 분(Minute)을 직접 숫자로 타이핑하는 편집 모드로 전환 |
| `Ctrl + R` | 현재 설정된 옵션값으로 즉시 가짜 세션 시작 |
| `Ctrl + S` 또는 `s` | 현재 옵션값을 기본값으로 영구 저장 (`~/.config/imposter/config.toml`) |
| `q` 또는 `Esc` | 설정을 저장하지 않고 마법사 즉시 종료 |

---

## 3. 비-TTY 환경에서의 동작 (Fallback)

SSH 파이프나 CI 환경처럼 터미널의 Raw Mode와 대화형 입력을 지원하지 않는 환경에서 `-i`를 호출할 경우, `ratatui` 전체 화면 대신 표준 입출력(`stdin`/`stdout`)을 통한 순차적 텍스트 질문-답변 모드로 자동 전환되어 안전하게 설정을 진행할 수 있습니다.
