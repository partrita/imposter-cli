# TUI 대화형 마법사

`imposter -i`를 실행하거나 설정 파일이 없는 최초 실행 시 `ratatui` 기반의 풀스크린 대화형 마법사가 열립니다.

## 주요 키보드 단축키

| 키 | 동작 |
|---|---|
| `↑` / `↓` 또는 `k` / `j` | 설정 항목 간 이동 |
| `←` / `→` 또는 `h` / `l` | 값 변경 (옵션 순환, 시간 ±5분) |
| `1` ~ `6` | 스타일 즉시 전환 (`claude`, `codex`, `opencode`, `pi`, `antigravity`, `classic`) |
| `t` | 테마 토글 (다크 ◰ ↔ 라이트 ☼) |
| `Enter` / `Space` | 옵션 순환 또는 시간 직접 입력 모드 진입 |
| `Ctrl + R` | 현재 설정으로 세션 시작 |
| `Ctrl + S` 또는 `s` | 현재 설정을 기본값으로 저장 (`~/.config/imposter/config.toml`) |
| `q` / `Esc` | 마법사 종료 |

우측 패널에는 선택한 스타일과 테마, 개발 스택, 린트 알림 여부가 즉각 반영되는 **실시간 라이브 프리뷰**가 렌더링됩니다.
