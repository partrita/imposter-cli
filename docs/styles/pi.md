# Pi Agent 스타일 (`pi`)

`earendil-works/pi` (`@earendil-works/pi-coding-agent`)의 고유한 미니멀 터미널 인터페이스를 재현한 스타일입니다.

---

## 1. 주요 레이아웃 특징

### 상단 블록 로고와 핫키 목록
상단에 Pi 특유의 2단 블록 아스키 로고(`▀█▀ / █▀█`)와 공식 도메인(`https://pi.dev`)이 청록색(Teal) 액센트로 표시되며, 단일 열 형태의 상세 단축키 목록과 컨텍스트 파일(`[context] AGENTS.md`)이 정돈되어 출력됩니다.

### 전체 폭 배경 박스 (Full-Width Tinted Boxes)
Pi 스타일은 각 영역마다 터미널 전체 폭을 채우는 전용 배경색 박스를 사용하는 것이 가장 큰 특징입니다:
- **사용자 메시지 박스**: `#343541` (라이트 모드 시 `#e5e7eb`) 배경 박스 안에서 타이핑 효과가 진행됩니다.
- **도구 성공 박스 (Tool Success)**: `#283228` 어두운 녹색 배경 박스 안에서 파일 읽기, 코드 편집, 터미널 실행이 감싸집니다.
- **도구 에러 박스 (Tool Error)**: 린트 실패 시 `#3c2828` 붉은색 배경 박스로 전환됩니다.
- **할 일 박스 (Todo)**: `#282832` 짙은 보라빛 배경 박스 안에서 작업 목록이 표시됩니다.

### 사고 중 전개
도구 실행 전 `Thinking... (ctrl+t to expand)` 문구가 단독 줄로 표시되며 모델의 깊은 사고 과정을 암시합니다.

### 정밀한 `footer.ts` 토큰/비용 원격 메트릭 바
턴 하단에는 실제 Pi의 `footer.ts` 로직을 본뜬 실시간 상태선이 출력됩니다:
```text
────────────────────────────────────────────────────────────────────────────
~/code/distributed-cluster (main)
↑1.2k ↓340 R2.8k W410 $0.042 24.1%/200k (auto)   (anthropic) claude-sonnet-4-5 • high
```
- 업로드 토큰(`↑`), 다운로드 토큰(`↓`), 캐시 읽기/쓰기(`R`/`W`), 계산된 비용, 200k 컨텍스트 대비 사용률(`%`)이 매우 사실적으로 표시됩니다.

## 2. 실행 명령어

```bash
# Pi 스타일 실행
imposter --style pi

# Pi 스타일 라이트 모드 실행
imposter -s pi --light
```
