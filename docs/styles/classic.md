# Classic 시스템 로그 스타일 (`classic`)

`rust-stakeholder` 원작의 레거시 시스템 엔지니어링 로그 모드입니다.

## 주요 화면 구성

- **부팅 시퀀스**: 프로그레스 바 애니메이션 `[████████░░░] 73%`
- **시스템 로그**:
  - `✓ inspected <file> (194 lines)`
  - `✓ p99 latency 38 ms · throughput 14.2k req/s`
  - 레벨별 기술 전문 용어(Jargon) 및 네트워크 트래픽 로그

```bash
imposter --classic
# 또는
imposter --style classic
```
