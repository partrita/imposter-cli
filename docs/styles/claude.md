# Claude Code 스타일 (`claude`)

Anthropic의 공식 터미널 에이전트인 `Claude Code v2.1`의 시각 디자인을 정밀하게 모사한 스타일입니다. `imposter`의 기본 스타일이기도 합니다.

---

## 1. 주요 레이아웃 특징

### 상단 환영 상자 (Welcome Banner)
터미널 너비에 맞춰 2단 분할 상자를 출력합니다. 좌측에는 Claude의 상징적인 픽셀 마스코트 'Clawd'(`▐▛███▜▌`)와 모델명(`Opus 4.6 · Claude Max`), 작업 디렉터리가 배치되며, 우측에는 세션 시작 팁과 단축키 안내가 들어갑니다. 폭이 좁은 터미널에서는 1단 중앙 정렬 상자로 유연하게 전환됩니다.

### 프롬프트 타이핑 애니메이션
상하 구분선(`──────────────────────────────────`) 사이에 주황빛 액센트의 `❯` 프롬프트 기호와 함께, 자연스러운 타자 속도(글자당 7ms)로 사용자 질의가 타이핑됩니다.

### 툴 실행 및 트리 출력
- **도구 호출**: 따뜻한 테라코타 주황색 액센트의 불릿(`⏺`) 기호와 함께 `⏺ Read(...)`, `⏺ Update(...)`, `⏺ Bash(...)` 형태의 도구 실행문이 나타납니다.
- **결과 트리**: 도구 실행 결과는 `⎿` 분기 기호와 함께 2칸 들여쓰기된 트리 구조로 펼쳐집니다. (예: `⎿ Read 194 lines (ctrl+o to expand)`)
- **코드 패치 디프**: 빨간색 삭제 라인(`-`)과 녹색 추가 라인(`+`)이 줄 번호와 함께 직관적인 diff 블록으로 렌더링됩니다.

### 생각 중 스피너 (Simmering Spinner)
사고 과정에서는 `✻ Simmering… (esc to interrupt · 4s · ↓ 2.1k tokens)` 형태의 문구가 6프레임 아스테리스크 스피너 회전 애니메이션과 함께 출력됩니다.

### 하단 완료 상태바
턴이 완료되면 소요 시간과 토큰 수, 예상 비용이 계산되어 출력되며, 하단에는 실제 Claude Code 특유의 키 안내문인 `⏵⏵ accept edits on (shift+tab to cycle)`이 회전 힌트로 표시됩니다.

---

## 2. 실행 명령어

```bash
# 명시적 스타일 지정
imposter --style claude

# 단축 플래그 사용
imposter --claude

# 라이트 모드로 실행
imposter --claude --light
```
